# English study notes with a Polish–English glossary

English | [Polski](2026-10-04-language-policy.pl.md)

Status: implemented

## Problem

The repository must support mathematical modeling study, Polish class vocabulary,
and English technical resources without requiring every study explanation to be
maintained twice. The user also requested decision records in both languages.

## Decision

Study notes and MATLAB explanations are English. A shared Polish–English glossary
preserves terminology needed in class. Supplied tasks retain their original text
with attribution. Repository guides and decision records have English and Polish
sibling files, updated together. Executable MATLAB code is shared.
The user selected the glossary approach on 2026-10-04 for the time being.

## Alternatives considered

**Full English and Polish notes:** considered for revision in either language,
but every mathematical correction would require updating two explanations.

**English notes with selected Polish summaries:** considered as a lighter option;
not selected for the first iteration because a glossary addresses the immediate
terminology need with less parallel prose.

## Consequences

There is one main study narrative and a smaller bilingual documentation set.
Terminology still needs review against class usage. Full Polish explanations can
be added later through a superseding decision; they are not required now.
